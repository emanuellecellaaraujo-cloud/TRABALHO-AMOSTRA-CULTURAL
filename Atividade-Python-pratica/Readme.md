# 🚀 Atividade Prática - Automação em Python

## 📝 Descrição do Projeto
Este projeto foi desenvolvido como parte de uma atividade acadêmica/prática de programação. Consiste em um script funcional escrito em **Python 3** projetado para resolver um problema específico de forma automatizada e limpa.

O objetivo principal é demonstrar o domínio na criação de scripts estruturados, tratamento de exceções, organização de repositórios e documentação técnica clara para desenvolvedores.

## ⚙️ Funcionalidades principais do Script
*   **Entrada de dados dinâmica:** Recebe e valida informações inseridas pelo usuário via terminal.
*   **Processamento lógico:** Executa cálculos ou manipulações de dados de forma automatizada.
*   **Tratamento de erros (`try/except`):** Evita que o programa quebre caso o usuário digite valores inválidos.
*   **Exibição limpa:** Retorna os resultados formatados de maneira organizada no console.

## 🛠️ Tecnologias e Ferramentas Utilizadas
*   **Python 3.x** (Linguagem de programação)
*   **Git & GitHub** (Controle de versão e hospedagem do código)

## 🚀 Como Executar o Projeto em sua Máquina

### 📋 Pré-requisitos
Antes de rodar o script, certifique-se de ter instalado:
*   [Python 3 instalado](https://python.org) no seu sistema operacional.
*   Um terminal (Prompt de Comando, PowerShell ou Terminal do Linux/Mac).

### 🔧 Passo a Passo para Execução

1. **Clone este repositório para o seu computador:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta dedicada à atividade:**
   ```bash
   cd atividade-python-pratica
   ```

3. **Execute o arquivo do script Python:**
   ```bash
   python script.py
   ```
