# Atividade Prática: Automação de Saudação e Verificação de Sistema

##  Descrição do Projeto
Este projeto consiste em um script simples em Python desenvolvido para demonstrar conceitos básicos da linguagem, como manipulação de strings, uso de bibliotecas nativas (`os` e `datetime`), estruturas condicionais e funções. O script exibe uma saudação personalizada com base no horário atual do sistema e informa o sistema operacional que está executando o código.

---

##  Como Executar o Projeto

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina:
* [Python 3.x](https://python.org)
* Um terminal ou prompt de comando

### Passo a Passo

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegar até a pasta da atividade:**
   ```bash
   cd atividade-python-pratica
   ```

3. **Executar o script:**
   ```bash
   python script.py
   ```
